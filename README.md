# Python Deployment

A collection of simple Python and Streamlit applications created for practical learning and deployment.

## 📁 Project Contents

### 📊 Student Performance Dashboard

**File:** `deploy.py`

An interactive Streamlit dashboard for viewing and analysing student performance.

**Features:**

* Upload student CSV file
* Display student data using Pandas
* Class summary metrics
* Select individual students
* View subject-wise performance
* Student performance result using `if/else`
* Bar charts for visualization
* Filter students using a slider
* Radio buttons for different data views
* Date picker
* Time picker
* Multiple subject selection
* Attendance requirement checker
* Search student by name
* Class topper calculation

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/nityaaag/Python-Deployment.git
```

Open the project folder:

```bash
cd Python-Deployment
```

Install the required packages:

```bash
pip install streamlit pandas
```

Run the dashboard:

```bash
streamlit run deploy.py
```

Or:

```bash
python -m streamlit run deploy.py
```
